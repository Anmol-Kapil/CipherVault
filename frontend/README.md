# CipherVault frontend

The React interface for the local CipherVault application. See the [root README](../readme.md) for complete setup, storage details, API documentation, feature screenshots, and testing instructions.

From this directory, run `npm ci` then `npm run dev`. Start the backend from the repository root as described in the main README. Open http://127.0.0.1:5173.

Requests to `/api` are proxied to http://127.0.0.1:8000. Both servers are local only; no hosting setup is included.
